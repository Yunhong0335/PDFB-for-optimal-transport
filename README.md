# PDFB-for-optimal-transport
This GitHub project contains the code for implementing the PDFB splitting method for computing optimal transport related gradient flows, especially those with nonlinear mobility and cross diffusion models, proposed in our works [1, 2]. For the technical details, we recommend reading our original paper.

The file "Nonlinear_Mobility" contains the code for [1].

The file "Cross_Diffusion" contains the code for [2].

1. Yunhong Deng, Li Wang and Chaozhen Wei. “Efficient Primal-dual Forward-backward Splitting Method for Wasserstein-like Gradient Flows with General Nonlinear Mobilities.” arXiv preprint arXiv: 2504.12713 (2025).

2. Yunhong Deng and Chaozhen Wei. “A Primal-dual Forward-backward Splitting Method for Cross-diffusion Gradient Flows with General Mobility Matrices.” arXiv preprint arXiv: 2510.27660 (2025).
